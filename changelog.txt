== Changelog ==
## [1.0.3] - 2026-08-24

### Fixed

- `Class 'ChipApi' not found` fatal error on the payment/callback controllers when
  the PrestaShop class index has not picked up the module's `classes/ChipApi.php`
  (e.g. module copied into place or installed before the index was rebuilt).
  The module now exposes `Chip::getApi()` with an explicit `require_once` guard and
  the controllers call `$this->module->getApi()` instead of `ChipApi::getInstance()`
  directly (mirrors the 9.x module).

### Added (parity with chip-for-prestashop 1.7-9.x)

- Admin refund button on the order page (`displayAdminOrderContentOrder` hook) that
  refunds the full paid amount via `POST /purchases/{id}/refund/` and marks the order
  **Refunded** (`PS_OS_REFUND`). Includes the hidden `ChipRefund` admin tab + AJAX
  controller (`action=refund` and `action=testapi`).
- `ChipApi::refundPurchase()` method.

## [1.0.2] - 2026-08-19

### Added (parity with chip-for-prestashop 1.7-9.x)

- DuitNow QR / ShopeePay group resolution (dnqr > duitnow_qr, shopee_pay > razer_shopeepay) via `/payment_methods/` (mirrors chip-for-fluent-cart).
- `CHIP_CHECKOUT_TEXT` config: custom text shown under the "Pay with CHIP" button; empty = list configured payment methods.
- CHIP brand logo (replaces the old WHMCS logo).
- `.htaccess` root protection (Apache 2.4 / 2.2) per PrestaShop Marketplace mandatory technical rules.
- `docs/readme_en.pdf` — English user guide (PDF).

### Fixed

- Currency code sent uppercase (MYR not myr) — CHIP API rejects lowercase codes.
- `/public_key/` returns the PEM as a raw JSON string; `getPublicKey()` now handles both shapes so webhook signature verification works.
- Webhook fallback resolves the purchase id from the webhook body when there is no session cookie (webhook-only payments).


## [1.0.0] - 2026-08-18

### Added

- CHIP Collect payment gateway module for PrestaShop 1.6.x.
- "Pay with CHIP" payment method on the order page (`displayPayment` hook).
- Payment flow: builds payment via `POST /purchases/`, redirects to CHIP checkout page.
- Webhook callback with X-Signature verification (RSA SHA-256) and fallback to `GET /purchases/{id}/`.
- Idempotent order validation (`validateOrder`; `extra_vars['transaction_id']`).
- Payment method whitelist configuration (HelperForm).
- Payment confirmation message on the order confirmation page (`displayPaymentReturn`).
- Payment method display names matching CHIP-API-SPEC.md (FPX, FPX B2B1, DuitNow QR, Card, Atome, GrabPay, Maybank QR, ShopeePay, Touch 'n Go, Crypto Coin).
